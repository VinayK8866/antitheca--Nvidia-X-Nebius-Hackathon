## 1. Challenge Overview

Build a working AI system on open, independent infrastructure and own the entire stack.
Submissions must run on **Nebius Token Factory** or **Nebius AI Cloud** and use at least one **NVIDIA open source model** (e.g., Nemotron family).

---

## 2. Tracks & Requirements

### Primary Target: Personal AI Track
> **"Build an always-on, private assistant that works for you while keeping your data under your control. Give it persistent memory, reusable skills, access to the tools and information you choose, and the ability to carry out tasks across your daily workflows."**
- **Core Requirements**:
  - Must use at least one NVIDIA open source model (Nemotron).
  - Tools suggested: NVIDIA NemoClaw, OpenShell, Hermes Agent, Nebius Serverless.
  - Epistemic privacy & local sovereignty over personal data.

### Other Tracks for Reference:
- **Best Apps and Agents Track**: Productivity tools, copilot or self-running workflows powered by Nemotron models on Token Factory (reach for Nemotron 3 Ultra for reasoning, Nano/Super for fast calls).
- **Coding and Agentic Engineering Track**: Agents that write, run, and test code.
- **Physical AI Track**: Embodied & edge agents (Jetson, robotics, IoT).

### Bonus Track: Best Use of Tavily ($3,000 Cash)
- Seamless integration of Tavily's autonomous search and fact-checking API into the agent loop.

## 4. Submission Checklist

1. **A Working Project**: Running live on Nebius Token Factory using NVIDIA Nemotron models.
2. **Category Selection**: Personal AI Track (+ check Tavily bonus box).
3. **Project Description**: Clear explanation of what was created, why, and how it works.
4. **Working Demo URL**: Hosted web application link (Vercel frontend + Nebius/cloud backend).
5. **Demo Video**: Public YouTube video **≤ 3 minutes** demonstrating:
   - Real-time interaction with the application.
   - Nebius Token Factory console / API logs in action.
   - NVIDIA Nemotron model inference (Ultra 550B & Nano 30B).
   - Tavily search verification loop.
6. **Public Code Repository**: GitHub repo with:
   - Visible Open Source License at the top (MIT / Apache 2.0).
   - Clear `README.md` with step-by-step setup and local running instructions.
   - Architectural diagrams and clear technical explanation.
7. **Feedback**: Written feedback on Nebius Token Factory, AI Cloud, and NVIDIA Nemotron models.

## 6. Official Evaluation Rubric

Judges evaluate based on four distinct pillars:
1. **Technical Execution & Architecture (25%)**:
   - Clean utilization of Nebius Token Factory and NVIDIA Nemotron models.
   - Model tiering efficiency (using Ultra for heavy reasoning, Nano for fast classification).
   - Epistemic privacy isolation (local SQLite WAL, data sovereignty).
2. **Impact & Practical Utility (25%)**:
   - Does this solve a genuine pain point that people actually experience?
   - Solves the "write-only graveyard" problem of saved content and bookmarks.
3. **Novelty & Innovation (25%)**:
   - Cognitive Replay (offline sleep synthesis).
   - Adversarial Challenger (belief stress-testing vs sycophancy).
   - Proactive Knowledge Arbitrage (pushing insights without prompting).
4. **Completeness & Polish (25%)**:
   - Stunning UI/UX design (dark glassmorphism, responsive 3D graph).
   - Clean documentation, architecture diagrams, smooth video demo.
